# ماشین‌حساب قیمت‌گذاری گوشت

برنامه فارسی و راست‌به‌چپ برای محاسبه قیمت فروش قطعات گوسفند و گاو.

## اجرا

```bash
npm install
npm run dev
```

## محاسبات

1. در مرحله اول **قیمت خرید هر کیلوگرم** و **سود کل گوشت** را وارد کنید.
2. در مرحله دوم وزن قطعات فعال را تعیین کنید.
3. هزینه خرید کل = قیمت خرید هر کیلو × مجموع وزن قطعات فعال.
4. مبلغ هدف فروش = هزینه خرید کل + سود کل.
5. نرخ پایه = مبلغ هدف فروش ÷ مجموع وزن قطعات فعال.
6. در صفحه قیمت‌گذاری قطعات در ردیف‌های کوچک نمایش داده می‌شوند؛ دکمه ⓘ جزئیات وزن، سهم فروش و مجموع فروش را در پنجره باز می‌کند. قفل 🔒 قیمت قطعه را ثابت نگه می‌دارد.
7. قیمت **هر کیلوگرم** به نزدیک‌ترین ۱٬۰۰۰ تومان گرد می‌شود: `1,124,769.23` → `1,125,000`.
8. هنگام تغییر قیمت یک قطعه، مبلغ تغییرشده بین قطعات **دیگرِ باز** به نسبت وزن‌شان سرشکن می‌شود. نرخ هر کیلو در این قطعات ابتدا به اندازه یکسان تغییر می‌کند و بعد گرد می‌شود.
9. به‌دلیل گردکردن به ۱٬۰۰۰ تومان، محدودیت حداقل قیمت یا قفل‌ها ممکن است جمع دقیقاً با مبلغ هدف برابر نشود؛ اختلاف بالای ۱٬۰۰۰ تومان با رنگ قرمز نمایش داده می‌شود.

اطلاعات دام، وزن قطعات، قیمت‌ها، قفل‌ها و تنظیمات خرید در `localStorage` ذخیره می‌شوند. دکمه «پاک‌سازی کامل» آن‌ها را حذف می‌کند. اطلاعات نسخه قدیمی در صورت وجود وزن معتبر به قیمت خرید هر کیلو تبدیل می‌شود.

برای اجرای آزمون‌های قیمت‌گذاری: `npm test`.
